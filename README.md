# Gasless Soulbound Membership Platform — Assignment

Welcome. This is a **3–5 day take-home** for the Blockchain Developer role.

You've inherited a partially-built membership platform. Your job is to **finish it, harden it, and ship it like it's going to production**. The previous engineer left the codebase in a working-but-rough state. Some of what they wrote is fine. Some of it is wrong. Some of it is missing.

Treat the existing code the way you'd treat a real PR review on day one of a new job: **read it, don't trust it**.

## What's in the box

```
contracts/   Foundry project — Solidity contracts (UUPS SBT, paymaster, rewards, Safe module)
backend/     Node/TS service — event indexer, claim endpoint, Tenderly hooks, Postgres migrations
```

See [`ASSIGNMENT.md`](./ASSIGNMENT.md) for the full brief.
See [`FINDINGS.template.md`](./FINDINGS.template.md) for the deliverable template.

## How you'll be evaluated

We care more about **how you think** than how much you ship. A small, correct, well-defended submission beats a large, mostly-working one.

We expect you to use AI tools (Claude Code, Cursor, Copilot — whatever you use day to day). What we're measuring is **your judgment over the output**: did you read the code, did you catch the bugs, did you understand the tradeoffs.
